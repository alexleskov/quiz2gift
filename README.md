# Конвертер тестов iSpring (.quiz) → GIFT для Teachbase

Одностраничный сайт: пользователь перетаскивает `.quiz`-файл и скачивает готовый
файл для импорта в Teachbase. Конвертация выполняется целиком в браузере
(на JavaScript), файлы на сервер не отправляются.

## Файлы

- `index.html` — страница (дизайн, drag-and-drop, скачивание результата)
- `quiz2gift.js` — ядро конвертера (общее для браузера и Node.js)

## Как опубликовать

### GitHub Pages (бесплатно, нужен аккаунт GitHub)

1. Создайте репозиторий (например `quiz2gift`) и загрузите в него `index.html` и `quiz2gift.js`.
2. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / root → Save**.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/quiz2gift/`.

### Netlify Drop (проще всего, без командной строки)

1. Откройте https://app.netlify.com/drop
2. Перетащите на страницу папку с `index.html` и `quiz2gift.js`.
3. Получите публичную ссылку сразу (бесплатный тариф достаточен).

### Локальная проверка

Откройте `index.html` в браузере двойным щелчком — всё работает и с `file://`
(единственная внешняя зависимость — JSZip с CDN, нужен интернет).

## Поддерживаемые типы вопросов

Одиночный выбор, множественный выбор, верно/неверно, свободный ответ,
числовой, соответствие, упорядочивание, эссе.

Пропускаются с предупреждением (в GIFT не представимы): «укажи область на картинке»,
«банк слов», «перетаскивание», шкала Ликерта.

## Проверка логики в Node.js

```bash
npm install jszip
node test.js   # сравнивает вывод с Python-версией quiz2gift.py
```
