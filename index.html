Конвертер тестов iSpring → GIFT

Перетащите файл .quiz (iSpring QuizMaker) — получите файл для импорта в Teachbase.
Конвертация происходит целиком в вашем браузере, файлы никуда не отправляются.

Перетащите сюда .quiz файл
или нажмите, чтобы выбрать файл на компьютере · можно несколько файлов сразу

Результаты

Что конвертер умеет

  • Преобразует тест iSpring QuizMaker (.quiz) в файл формата GIFT для импорта в Teachbase — одиночный и множественный выбор, верно/неверно, свободный ответ, числовой вопрос, соответствие, упорядочивание, эссе.
  • Сохраняет группы вопросов iSpring как категории GIFT ($CATEGORY).
  • Переносит картинки из вопросов в ZIP-архив и подключает их блоком [files].
  • Экранирует специальные символы GIFT и защищает от типовых ошибок, из-за которых Teachbase отклоняет весь файл импорта.
  • Обрабатывает несколько файлов подряд: перетащите сразу все тесты.

Ограничения

  • Вопросы «укажи область на картинке», «банк слов», «перетаскивание» и шкала Ликерта в GIFT не представимы — они пропускаются с предупреждением в карточке результата.
  • Числовые вопросы конвертируются без допуска (верен только точный ответ) — проверьте их после импорта.
  • Обратная связь за ответ, баллы за вопрос, перемешивание вариантов и лимиты времени GIFT не переносит — настраивается в редакторе теста Teachbase после импорта.
  • Работа конвертера не гарантируется для тестов из старых версий iSpring: типы вопросов, которых не было в проверенных файлах, конвертируются по эвристикам — сверяйте результат с оригиналом.
Как загрузить результат в Teachbase
  1. Создайте тест (в курсе или материал «Тест» нового типа).
  2. Откройте импорт в формате GIFT и выберите скачанный файл: .txt — для теста в курсе, .zip — для теста нового типа (с картинками).
  3. В тестах нового типа выберите режим «Заменить вопросы», если тест пустой.
  4. Проверьте вопросы после импорта: баллы, перемешивание и лимиты времени GIFT не переносит.
